## R1 régime 实验（判决：不改，维持现状）

本地 H100、n=24 配对、五臂。结论：**现在的做法（空画布 + 位置和氨基酸一起钉 + 全局共生成）最好**。

```
换 régime        IP_native vs CO_native   5:19  p=0.0066  显著更差
换位置来源        CO_pocket vs CO_native   6:18  p=0.023   显著更差
IP 把链弄坏       IP_pocket 21.9% 塌链 vs CO 两臂 0%
身份内容没贡献     IP_pocket vs IP_shuf    11:13  p=0.84    打平
多步扩散修不回来   400 步同向, IP_native Δ+7.66 → +12.95
```

"身份内容打平"复现了已有记录「定位能力在结构通道里不在身份通道里」（p=0.665），
而同一判据换成结构 bit 就显著（6.08Å vs 错配 10.45Å，p=0.0009）⇒ **载体错，不是判据瞎**。
而结构 bit 外部供不进来（EC 标签 0.5446 vs 常数 0.5397、检索天花板 0.58）。

## 过程中自己犯的错（都已修，记下来免得再犯）

1. 采样参数没对齐生产（`annealing@2.2:1.0` vs 默认），据此错报"无条件草稿大量塌缩" —— 已撤回
2. 判据不可比：k=8-9 的"最近一对"机械小于 k=3 的参照 6.87/12.56 ⇒ 改用 k 稳健的中位+占比
3. 口袋判据第一版挑出连续序列段（回转 1.6-3.0Å）⇒ 按天然核心间距分布重写
4. `pgrep -f` / `pkill -f` 自匹配 **5 次**（采样器、链、进程计数、两次杀 sglang）⇒ 一律改 flock 或字面串拆开
5. 审计器把 plddt 的 51 当"表外位置"，报 59.78% 假阳 ⇒ 排除该行自身数值后真值 0.33%
6. `logits.float()` 会在 vocab 248,077 上物化 13.2GB ⇒ 先按监督位置选再转
7. val 取前 N 条 ⇒ 全是 R1（R2-R4 的 n=0）⇒ 改按轮均匀采样
